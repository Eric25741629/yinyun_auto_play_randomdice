# Demo Recording

README 的 Demo 區塊預留給實機錄製素材。由於遊戲畫面與 Emulator 狀態不在 repository 中，不能用靜態素材冒充實際操作影片。

## Recommended recording

錄製一段 20–60 秒的無個資 Demo，至少包含：

1. 兩個 Emulator 啟動並連線。
2. 攻擊方建立合作房間。
3. 輔助方取得房號並加入。
4. 遊戲中自動辨識盤面與執行移動／合成。
5. 結算畫面與下一輪流程。

建議輸出：

```text
docs/assets/demo.gif
# or
docs/assets/demo.mp4
```

加入素材後，在 README 的 Demo 區塊取消註解對應連結即可。錄製時請遮蔽帳號、房號、個人通知及其他敏感資訊。
